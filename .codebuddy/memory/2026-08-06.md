# 2026-08-06

## 修复：Runner.xcscheme StoreKit 路径错误

**根因**：`ios/Runner.xcodeproj/xcshareddata/xcschemes/Runner.xcscheme` 第 91 行
`<StoreKitConfigurationFileReference identifier = "../Runner/Configuration.storekit">`。
scheme 文件位于 `xcshareddata/xcschemes/`，`../Runner/` 从该目录解析指向不存在的路径，导致模拟器读不到本地 IAP 商品 → `queryProductDetails got 0/5` + `storekit_no_response`。

**修复**：改为 `../../Runner/Configuration.storekit`（上两级到 `ios/` 再进 `Runner/`）。
同样需在 Xcode 完全退出后改，否则被还原。

**验证**：重开 Xcode（带 locale `LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`），确认 Run configuration 为 Debug，⌘R，期望 `🔵 IAP queryProductDetails: got 5/5`。
